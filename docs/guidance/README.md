# Guides

How to use Omnia's larger features, step by step.

| Feature | Guide | What it covers |
|---|---|---|
| Self-hosted models | [local-server](local-server/README.md) | Connecting Omnia to your own model server, running one, and building your own |
| Smart Notes | [smart-notes](smart-notes/README.md) | Generating a note's fields: providers, tools, batches, and what a regeneration may replace |
| Sync | [sync](sync/README.md) | Copying decks, note types and settings from another computer |
| Typing Accuracy | [typed-accuracy](typed-accuracy/README.md) | Turning how well you typed an answer into the review grade |

The other plugins (Phrase Check, Note Maintenance, Word Lookup, Audio Speed, Auto Flip, Display
Interval, Overdue Guard) are small enough that their settings explain themselves: hover any
option in the plugin's panel (*Tools → Omnia* → the plugin → *Configure…*) for what it does.

**Try new things on a spare profile first.** Anki → *File → Switch Profile → Add*. Batch
generation and Sync change your collection on purpose; a spare profile lets you learn them
without touching the cards you study.
